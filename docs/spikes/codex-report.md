# Verification report

## Blocking (design cannot work as written)

- **`codex resume <id>` as a live viewer of `codex exec`** — source inspection shows `exec` starts its own in-process server using memory channels; another terminal cannot attach to that running server through the session ID. Evidence: [0.163.0 exec startup](https://github.com/openai/codex/blob/rust-v0.163.0/codex-rs/exec/src/lib.rs#L987), [transport implementation](https://github.com/openai/codex/blob/rust-v0.163.0/codex-rs/app-server/src/in_process.rs#L1).
- **PreCompact blocks and tells the lead to write a handoff** — blocking exists, but the output is not a model-facing instruction; `systemMessage` is discarded. Blocking recovery compaction fails the current request with the context-limit error, rather than granting a handoff turn. Evidence: [PreCompact documentation](https://code.claude.com/docs/en/hooks#precompact).
